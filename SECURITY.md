# Security Policy

## Supported Versions & Official Releases

| Version / Branch | Supported | Notes |
| :--- | :--- | :--- |
| `main` (Latest `vX.Y.Z` Release) | Yes | Actively maintained official release stream |
| Forks, Mirrors, and Older Tags | No | Unverified and unsupported |

Official executables are distributed exclusively from the primary `DontKwo/time-is-money-sim` repository on GitHub (`main` branch and official [Releases](https://github.com/DontKwo/time-is-money-sim/releases/latest)).

- **Fork Safety Warning**: Do **not** download or run executables from forked repositories or third-party mirrors unless you have verified the source code yourself and confirmed they contain no malware. Only `DontKwo/time-is-money-sim` `main` builds are maintained by the author.
- **OS Security Prompts**: Because Life Money Simulator is published independently without paid commercial code-signing certificates, Windows SmartScreen and macOS Gatekeeper may warn that the download is unrecognized or potentially unsafe. Review [Desktop Installation Guide](docs/INSTALLATION.md) and bypass security prompts strictly at your own discretion.

## Reporting a Vulnerability

If you discover a security issue in `DontKwo/time-is-money-sim`:

1. **Do not** disclose exploit details or credentials in a public GitHub Issue.
2. Open a [Private Vulnerability Report](https://github.com/DontKwo/time-is-money-sim/security/advisories/new) on GitHub (or contact `@DontKwo` via GitHub profile).
3. Include reproduction steps, operating system, and any suggested fix.
