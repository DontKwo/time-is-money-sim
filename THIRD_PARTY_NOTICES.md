# Third-Party Notices

## Public Economic Data Sources

None bundled. When modeling historical or benchmark series externally, source public series from Federal Reserve FRED or the World Bank.

## Runtime Libraries

Life Money Simulator dynamically uses open-source Python packages declared in `pyproject.toml`:

- **Pydantic** (`MIT`): Scenario configuration validation.
- **PyYAML** (`MIT`): YAML scenario loading.
- **NumPy** (`BSD-3-Clause`): Vectorized distributions and Monte Carlo sampling.
- **Pandas** (`BSD-3-Clause`): Transaction ledgers and daily analytics rollups.
- **Matplotlib** (`PSF-based`): Balance, net worth, cashflow, Monte Carlo fan, and tornado chart rendering.
